How it works

선택은 단순하게, 과정은 투명하게.

무엇을 바꾸는지 숨기지 않습니다. 먼저 미리 보고, 필요한 구성만 선택한 뒤, 실제 로그로 전 과정을 확인합니다.

01

내 운영체제에서 시작

처음이라면 아래 v0.14.0 GUI ZIP을 받아 시작하세요. macOS용 GUI와 실험적으로 제공하는 Windows용 GUI가 있으며, Linux는 v0.14.0 소스로 설치합니다.

02

기본 AI 구성, 설치와 미리보기는 별도

v0.14.0 GUI와 일반 무프로필 CLI 설치의 기본값은 ai입니다. GUI의 기본 동작은 설치이며, 미리보기는 별도 버튼입니다. recommended는 ai의 별칭이 아닌 더 넓은 개발 구성입니다. full, minimal, work도 명시적으로 선택할 수 있습니다.

03

설치 후 직접 확인하고 첫 프로젝트로

설치와 실행 파일 검사를 마친 뒤 새 빈 연습 폴더에서 Claude Code 또는 Codex를 여세요. 미리보기·실패·취소만으로 첫 실행 기능이 열리지는 않습니다. 새 Mac에서 Terminal로 설치를 이어 했다면 GUI로 돌아와 설치 결과 확인을 실행하세요. 로그인과 첫 프롬프트 검토·전송은 직접 하며, 복사 버튼은 클립보드에만 넣습니다. 첫 프로젝트 안내를 따르세요.

Safety by design

빠른 것보다, 기존 환경 보호가 먼저.

새 컴퓨터뿐 아니라 이미 사용 중인 컴퓨터에서도 실행할 수 있도록 기존 설정 보존과 실행 전 확인을 우선합니다.

기존 설정 보존 기존 도구와 설정을 먼저 감지하고, 관리 대상 셸·프로필 파일은 변경 전에 백업합니다.
Dry Run 컴퓨터를 바꾸기 전에 실행할 작업과 대상 경로를 먼저 확인할 수 있습니다.
반복 실행 가능 같은 설치를 다시 실행해도 설정 블록이 중복되거나 손상되지 않습니다.
자동 제거 미지원 v0.14.0은 기존 도구와 키트가 설치한 도구를 확실히 구분할 수 없어 자동 제거를 지원하지 않습니다. 개별 도구의 공식 제거 안내를 따르고, 설정과 백업은 직접 확인하세요.

One coherent setup

도구를 모으는 데서 끝나지 않습니다.

기본 ai는 Git, Node LTS/npm, Claude Code, Codex, 안전 훅과 최소 PATH를 준비합니다. Python, Go, Rust, Docker, WSL, Bun, uv, 셸 꾸미기, 폰트와 선택 CLI 묶음은 제외합니다. 더 넓은 개발 도구는 recommended 등 명시적 프로필로 선택합니다. Hermes는 macOS·Linux의 고급 에이전트 구성에서만 별도 선택하며, ai는 상속된 HERMES=1도 무시합니다. v0.14.0은 gajae-code (gjc), lazycodex를 설치하거나 기존 도구와 설정을 삭제하지 않습니다. 설치 후 새 터미널에서 확인하세요. macOS doctor는 저장된 프로필을 추론하며 AI JSON은 --profile ai --doctor-json을 사용합니다. Linux의 단독 --doctor는 AI 범위, Windows의 단독 -Doctor는 전체 범위이므로 AI 검사에는 -Profile ai -Doctor가 필요합니다. 명시적 개발 프로필의 doctor는 전체 도구 목록 점검을 유지하며, 어떤 로컬 검사도 제공자 인증을 확인하지 않습니다.

  • Git
  • Homebrew (macOS)
  • mise (Linux AI·개발 구성)
  • Node LTS/npm
  • Python (개발 구성)
  • Go (개발 구성)
  • Rust (개발 구성)
  • starship (개발 구성)
  • Docker (선택)
  • Claude Code
  • Codex
  • Hermes (macOS·Linux 고급 선택)
