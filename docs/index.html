How it works

선택은 단순하게, 과정은 투명하게.

무엇을 바꾸는지 숨기지 않습니다. 먼저 미리 보고, 필요한 구성만 선택한 뒤, 실제 로그로 전 과정을 확인합니다.

01

내 운영체제에서 시작

다운로드한 설치 앱 또는 플랫폼별 안내에서 같은 설치 흐름을 시작합니다.

02

구성을 고르고 미리보기

전체·최소·회사 PC용 프로필을 고르고, 실제 변경 전에 작업 목록을 확인합니다.

03

설치하고 바로 검증

필요한 도구를 공식 배포처에서 설치하고 버전·경로·설정 상태까지 확인합니다.

Safety by design

빠른 것보다, 되돌릴 수 있는 것이 먼저.

새 컴퓨터뿐 아니라 이미 사용 중인 컴퓨터에서도 실행할 수 있도록 보존·검증·복구를 설치 과정의 일부로 만들었습니다.

기존 설정 보존 기존 도구와 설정을 먼저 감지하고, 관리 대상 셸·프로필 파일은 변경 전에 백업합니다.
Dry Run 컴퓨터를 바꾸기 전에 실행할 작업과 대상 경로를 먼저 확인할 수 있습니다.
반복 실행 가능 같은 설치를 다시 실행해도 설정 블록이 중복되거나 손상되지 않습니다.
제거와 수동 복구 키트가 관리하는 설정을 정리하고 백업은 수동 복구용으로 남깁니다. Homebrew·Git 정보·폰트 같은 외부 상태는 유지합니다.
